# Taurvia desktop app

Version **0.5.2**. See the [root README](../../README.md) for architecture, setup, and security docs.

Dashboard, send, receive, activity, and lock work on Solana, Ethereum, Bitcoin, and Sui. Swap uses Jupiter on Solana, 0x on Ethereum, and Thorchain when Bitcoin is the source (`/swap`).

```bash
pnpm install
pnpm tauri dev
```
