# Taurvia desktop app

Version **0.5.3**. See the [root README](../../README.md) for architecture, setup, and security docs.

Dashboard, send, receive, activity, and lock work on Solana, Ethereum, BNB Chain, Bitcoin, and Sui. Swap is Jupiter (Solana), 0x (Ethereum), and Thorchain when Bitcoin is the source — not Sui or BNB Chain.

```bash
pnpm install
pnpm tauri dev
```
